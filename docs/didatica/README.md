# Didática para jogos

Material de consulta para desenhar jogos de japonês, aproveitado em 15/10/2026 da pesquisa de conteúdo, do planejamento dos 34 jogos e do protótipo Gojūon Board.

- **[Guia de design didático](guia-de-design-didatico.md).** É o que usar. Cobre o que um jogo pode dizer que treina, kana e fonologia, recuperação e evidência, transferência, áudio, feedback, acessibilidade e um reservatório para jogos além de kana.
- **[origem/](origem/README.md).** Cópias dos documentos originais, para rastrear de onde veio cada ideia.

Os documentos estão em português, a língua da pesquisa e do blueprint. A interface dos jogos continua em inglês.

Não é currículo nem trilha. Cada jogo pratica algo específico e diz isso com honestidade (blueprint v7, princípio 3).
